## What I learned
- `Last-Modified` and a 304 can be fake: the CMS sets the request time.
- A query parameter can be decoration. The server ignores BNetzA's `v`; the redirect from the bare path tells the real one.
- An `.html` link can be a 301 to a PDF. The type comes from the response, not the URL.
- Hash the content element, not the page: menus change on their own.
- `httpx.MockTransport` serves a whole fake site to the tests.
- `pool.map` hands results back in start order. `as_completed` hands them back as they finish.
- SIGKILL loses buffered stdout: run 1's size line never reached the log.
- In a package, `from pkg.sub import f` inside `__init__` rebinds `pkg.sub` to the function `f` when they share a name.
- ruff never removes unused imports in an `__init__.py` on its own: they could be re-exports.
- "Gone" has to come from the page's own hrefs, not from what the crawl resolved.
