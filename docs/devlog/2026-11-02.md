## What I learned
- uv is for making sure it works similarly everywhere, not just this computer. 
- ruff format checks inconsistent spaces.
- ruff check looks for unused imports and variables.
- mypy is for verifying the types and whether they work together. like passing "None" where text is expected.
- pytest checks whether the code actually does what it should.
- pre-commit checks whether we did all the above checks before committing
- use uv add with --dev while installing tools that are only required for developing, and are not runtime dependencies. Because using plain uv add will install them as runtime dependencies, which is unnecessary for development tools like ruff, mypy, etc.
