# 05-11-2026

## What I did
- Checked formulas in the EnWG XML. Only one is an image (Anlage zu § 13g), and it was dropped silently.
- Text formulas use `<SUB>` and are already rendered as `H_{it}`.
- Fixed `<DT>` labels losing their subscripts (`Vit` instead of `V_{it}`).
- Compared 5 PaddleOCR models on the image. Only PaddleOCR-VL read it fully correctly.
- Added OCR with a JSON cache and put the LaTeX into the chunk where the image was.
- Added `uv run lawclerk ingest [statutes]`. With no kind it runs every kind, so later rulings are not mixed in by accident.
- Wrote ADR 0001 (formulas) and ADR 0002 (CLI).

## What I learned
- Plain OCR does not give LaTeX. I need a formula model.
- `render()` already writes the text of unknown elements, so no new case was needed.
- One image is not enough to trust the OCR.
- argparse from the standard library is enough for a small CLI with subcommands.
- The `[project.scripts]` entry in `pyproject.toml` is what makes `uv run lawclerk` work.

## What is still unclear

- The cache is in `data/`, so hand corrections are lost if I wipe it.
- The old "Hello" stub `main()` and `tests/test_main.py` are unused and still need deleting.
